# 理科プリント

小学1・2年の生活科から、小学3年〜中学3年の理科まで、単元ごとの練習プリントを作る 1 ファイルの Web アプリです。
「算数プリント」(Math-worksheet-generator)と同じしくみ・同じ見た目で作っています。

- 公開ページ: https://iamochiai-collab.github.io/Science-worksheet-generator/
- 作った人: 落合聡一

## できること

- **学年**: 小1・小2(生活科)、小3〜小6・中1〜中3(理科)
- **特別支援学校(知的障害)の段階**: 小学部1〜3段階(生活)・中学部1・2段階(理科)・高等部1・2段階(理科)。学習指導要領の段階と内容(A 生命、B 地球・自然、C 物質・エネルギー)にそって、学年べつの単元をならべなおしています
- **種類**
  - 基本問題 … ことばや しくみを答える問題(一問一答・（　）にことばを入れる・ア〜エからえらぶ・じゅんばんにならべる)
    - どの単元にも「まとめ(ことばをえらぶ・○×)」があります。〔ことば〕からえらぶ穴うめ、正しければ○・まちがいなら×、いくつかのものに○×をつける問題です(市販・無料の理科プリントによくある形を参考にしました)
  - 図・実験 … 図や表・グラフを見て答える問題(回路、こん虫や花のつくり、月の動き、てこ、天気図の記号 など)
  - 計算問題 … 密度・濃度・圧力・オームの法則・湿度・仕事 などの計算(考えるスペースつき)
  - 練習プリント … 1つの単元を、図 → 〔ことば〕の穴うめ → ○× → えらぶ → 計算 → 記述 の順に、おもて・うらの1〜2まいにまとめたもの(市販・無料の理科プリントの形にならいました)
  - 単元まとめテスト … 100点満点
- **難易度** ★1〜3、**小単元** だけのプリント、**答えのページ**(プリントにオレンジで書きこむ形)、**ふりがな**・**習っていない漢字はひらがなに**、**まとめて作る**(印刷・PDF・JPG)

## フォルダ

- `content/*.js` … 問題のもと(ふつうの日本語で書く)。ここを直す
- `tools/rika/annotate.js` … content に ふりがな `{漢字|かな}` をつけて `src/generators/<名前>/part1.js` に書き出す。読みのまちがいは `tools/rika/yomi.txt` で直す
- `src/template.html` … アプリ本体(算数プリントと同じもの。理科用に名前・種類・学年を変えている)
- `tools/build.py` … 1 ファイルにまとめて `docs/index.html`(公開用)と `build/test.html`(検査用)を作る

## 作りなおしと検査

```sh
npm install                          # はじめの1回(ふりがな用の kuromoji と playwright)
node tools/rika/annotate.js          # content → src/generators(ふりがなつけ)
python3 tools/build.py               # docs/index.html を作る
node tools/rika/check.js build/test.html 150         # 答え・図・数の組み合わせの検査
node tools/test/layout.js docs/index.html 結果.json 3,4   # はみ出し・番号のずれ(学年をしぼれる)
node tools/rika/render.js build/test.html r3-10 figure basic 2 1 out/a-   # 画像にして目で見る
```
